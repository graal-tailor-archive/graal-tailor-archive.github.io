# Graal Tailor Archive

Independent, partial restoration of public shield codes and graphics recovered from archived TaylorRichaards.com pages. This is not the original or official site.

The page uses a simple responsive gallery, search, image/GIF filters, and full setshield command copying. Images are embedded in index.html, so there are no live dependencies on Drippy Codeshop or the original image server.

## Privacy

The repository and GitHub Pages site are public. The page requests no search-engine indexing through its robots meta tag. This is not password protection or a guarantee that no one will find it.

## Sources

archive-manifest.json records each recovered code, original image URL, archive capture date, and image availability. Missing images are labeled; recovered codes have not been verified inside the game. Graphics belong to their respective creators.

## Maintenance

GitHub Pages publishes main from the repository root. To update the gallery, edit the catalog array in index.html. Keep exact filenames and the setshield prefix. Preserve the robots meta tag and the independent repository configuration.
